# Visual and functional QA — 2026-10-06

Scope: dev and DevStaging only. No production schema/master changes. Work is grouped by area: observe and record issues, make a batch of fixes, then validate.

## Block 1 — Public pages and account forms

Observed the deployed desktop login, signup, password recovery, pricing and features pages. Fixed small text-action hit areas, multiline button padding, password help, primary heading semantics, selected-role semantics and status announcements. Pricing cards no longer pretend to select a purchasable plan; the audience switch uses pressed buttons and the signup link remains the actual action. Removed outdated individual/small-job marketing, and clarified voluntary supplementation.

## Block 2 — Youth profile, onboarding and workspaces

Observed signed-in short onboarding, profile overview/CV/details and CV-method choices. The onboarding date appeared filled but the next step saw empty React state. Reading named submitted controls via FormData fixes this; the deployed browser advanced from step 1 to step 2 using the same date input. Added breathing room between profile copy/forms/actions, aligned CV lead copy with its heading, and enlarged quiet links, filter controls, supplementation checkboxes and chat menu/quick-reply controls. Long labels and narrow candidate/tab/modal layouts can wrap without squeezing icons or badges.

The initial API integration script signed out all sessions for a shared disposable actor, including the browser. Subsequent test cleanup uses local signout. This incident is not evidence of an application signout bug.

## Block 3 — Company workspace

Observed the synthetic company profile overview, company details, candidate empty state, chat empty state, notifications, and all three announcement steps. Legacy swipe navigation now resolves to the actual permitted view, and internal announcement switches update the URL so the main navigation stays aligned. Corrected stale copy describing optional questions as preceding submission.
