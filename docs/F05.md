## Problem och ändring

Tidigare spärrades uppdateringsknappen medan bakgrundsjobbet väntade eller bearbetades. Statushämtningsfel och köbegäransfel ignorerades och polling saknade slutgräns. Ett kompletteringsfel kunde dessutom presenteras som ett misslyckande efter en färdig bedömning.

- Status visar Beräknar, Klart, Preliminärt underlag eller Kunde inte uppdateras.
- Färdigt underlag visar tidpunkt från sparat cachesvar, köstatusens uppdatering eller slutfört direktanrop. Ingen tidpunkt påstås för preliminärt resultat.
- Bakgrundsstatus läses först. Befintliga färdiga resultat kräver ingen ny köbegäran. Hämtnings-/köfel syns och bakgrundsväntan begränsas till 60 sekunder; enskilda statusanrop till 12 sekunder.
- Direkt återförsök är åtkomligt även när bakgrundskön väntar. Endast ett pågående direktanrop spärrar knappen; autentisering, transport och JSON-läsning omfattas av 55 sekunders tidsgräns.
- Manuell uppdatering stoppar den aktuella observatören, så sena bakgrundssvar inte skriver över resultatet. Nya direkta uppdateringar är möjliga, och en ny kandidatvy startar observation igen.
- Tidigare underlag bevaras vid fel. Kandidatbyte återställer hela panelens tillstånd; gamla anrop avbryts. Kompletteringar hämtas separat efter lyckad analys.
- Befintligt auktoriserat API och databasens ägarkontroller används. Ingen ändring av schema, RLS, modeller eller faktiska matchningsregler.

## Verifiering

Godkända lokalt: TypeScript, riktad ESLint utan fel/varningar, `test:assessment-progress`, `test:matching`, `test:company-navigation`, `test:application-supplement`.

Det nya regressionstestet kör observatören och komponentens faktiska callbacks med simulerad transport: färdigt resultat, köstart, väntande jobb, timeout, RPC som aldrig svarar, nätverksfel, nekad köstart, terminalt fel, avbrytning/sena svar, åtkomligt direkt återförsök, cachetid, bevarat underlag, separat kompletteringsfel och lyckat nytt försök. Det är inte ett liveprov med OpenAI eller databas.

Produktionsbygge: `npm run build -- --webpack` passerar inklusive TypeScript, 50 statiska sidor och routemanifest.
