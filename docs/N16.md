# N16 – annons utan obligatoriskt platsantal

Reviderat användarbeslut 2026-10-18. Tidigare plan om nedräkning och automatiskt lyft efter anställning är ersatt. Reservation publicerades i `codex/n16-annonsflode-20261018`, commit `5da009b`, före kodändring.

## Beteende

- Annonsbyggaren frågar inte längre hur många företaget vill anställa. Företaget pausar/avslutar när rekryteringen är färdig.
- Kopior innehåller inte ett ärvt platsantal. Granskning av datum, lön och villkor finns kvar.
- Äldre lokala utkast behåller sina aktuella redigerbara uppgifter, bilder och steg. Ett gammalt platsantal, även ett ogiltigt sådant, ignoreras vid återställning och hindrar inte publicering.
- Databasfältet `jobs.open_positions` finns kvar för bakåtkompatibilitet. Gemensam createJob använder redan ett tekniskt standardvärde 1 när fältet saknas. Värdet visas inte som ett faktiskt behov och används inte för automatisk stängning/lyft. Befintliga annonsers värden skrivs inte om.
- Ingen migration eller ändring av registrering/godkännande av anställning. Ingen ändring av ägarkontroll, RLS, ansökningar eller chattar.

## Genomförd verifiering

- `test:job-copy`: kopiering av aktiv/pausad/stängd annons, originalisolering, separata matchkriterier, arbetsplatser, bild och lön, granskningskrav, främmande ägare/kontobyte; nya fall för gamla platsfält och utkaståterställning.
- `test:job-workplaces`: befintlig createJob fungerar utan open_positions, flera adresser och ägarkontroller (simulerad transport).
- `test:recruitment`, `test:recruitment-review`, `test:company-navigation` passerar.
- TypeScript och fullständigt `npm run build -- --webpack` passerar (50 sidor).
- Riktad ESLint: 0 fel, 1 befintlig img-varning på företagssidan. `git diff --check` passerar.
- Utvecklingsguidens 66 unika uppgifter och ankarlänkar kontrollerade. Idébankens tidigare ID:n bevarade; IDE-019 har uttryckligen avförts, inte raderats.

## Återstår före Klar

Inloggat webbtest på driftsatt dev: skapa annons utan platsantal, återställ gammalt utkast, publicera granskad kopia och kontrollera att originalet är oförändrat. Kontrollera manuell paus/avslutning och separat anställningsbekräftelse. Dessa liveflöden har inte verifierats i denna leverans; N16 står För granskning.

N17 gemensamma jobbtyper är nästa implementation. N18/F26/N19/N20/N21 har egna avgränsningar och acceptanskriterier; de är planerade och inte implementerade genom N16.
